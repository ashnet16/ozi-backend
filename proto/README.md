# Snapchain protos

The `.proto` files here are copied unchanged from
[farcasterxyz/snapchain](https://github.com/farcasterxyz/snapchain) at commit
`ff247c1173208b8d3f1b4af95ee10c9afeeb3792`, from `proto/definitions/`.

They are checked in so that the tests, the seed script and the poller image build
need no GitHub access. The Python modules compiled from them (`*_pb2.py`,
`*_pb2_grpc.py`) are generated by `make test` and by the poller image, and are
git-ignored.

To update them, delete `./snapchain` and run `make proto`, which clones the latest
Snapchain and copies its `.proto` files here. Then update the commit above.
